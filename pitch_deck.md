## Slide 5: The Tech Stack & Architecture
**Headline:** Built on modern, scalable, and low-maintenance tech.
**Bullet Points:**
*   **Frontend:** React 19 + TypeScript + Vite (Lightning fast, highly maintainable).
*   **Styling:** Tailwind CSS + Framer Motion (Premium, responsive UI).
*   **Backend & DB:** Supabase (PostgreSQL, Auth, Edge Functions - Zero server maintenance).
*   **Architecture:** Serverless. Very low running costs (currently $0-$45/mo).
**Visual:** Logos of React, TypeScript, Tailwind, and Supabase.
